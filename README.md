# kjn

## table-tennis-edge

A table tennis betting analysis app: point-level pricing model, player
ratings, a scanner for mispriced lines and arbitrage, a walk-forward
backtester and a local dashboard. See
[table-tennis-edge/README.md](table-tennis-edge/README.md), and the research notes in
[table-tennis-edge/docs/RESEARCH.md](table-tennis-edge/docs/RESEARCH.md).
